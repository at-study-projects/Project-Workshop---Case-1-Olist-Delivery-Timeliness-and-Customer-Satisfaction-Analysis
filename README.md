# В данном репозитории размещена итоговая работа по курсу «Аналитика данных» (МФТИ). В качестве проекта выбран кейс 1 из материалов курса. Наименование проекта - «Влияние на сроки доставки и оценки покупателей маркетплейса Olist».

---

### Проблематика кейса: исследование факторов, влияющих на своевременную доставку и удовлетворённость клиентов на основе данных электронной коммерции Olist.

---

### Задача: выяснить, какие факторы влияют на своевременность доставки заказов и оценки покупателей, и предложить рекомендации по сокращению задержек.

---

### Данные: [Brazilian E-Commerce Public Dataset by Olist (Kaggle)](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), 9 файлов (лежат в папке `data`).
